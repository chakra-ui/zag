A toggle is a two-state button for a single on or off option; for related
options, use [Toggle Group](/components/toggle-group)

**Features**

- Controlled and uncontrolled pressed state
- Optional indicator part for icons or labels
- `aria-pressed` for assistive technology

## Usage

<CodeSnippet id="toggle/usage.mdx" />

### Default pressed state

Use `defaultPressed` to start in the pressed (on) state when uncontrolled.

<Example id="ToggleDefaultPressed">

```tsx {2}
const service = useMachine(toggle.machine, {
  defaultPressed: true,
})
```

</Example>

### Controlled pressed

Use `pressed` and `onPressedChange` for controlled usage.

<Example id="ToggleControlled">

```tsx
const service = useMachine(toggle.machine, {
  pressed,
  onPressedChange(nextPressed) {
    setPressed(nextPressed)
  },
})
```

</Example>

### Value changes

When the pressed state changes, `onPressedChange` is called with the next
boolean value.

<Example id="TogglePressedChange">

```tsx {2-4}
const service = useMachine(toggle.machine, {
  onPressedChange(pressed) {
    console.log(pressed ? "on" : "off")
  },
})
```

</Example>

### Disabling the toggle

Set `disabled` to `true` to prevent interaction.

<Example id="ToggleDisabled">

```tsx {2}
const service = useMachine(toggle.machine, {
  disabled: true,
})
```

</Example>

### Programmatic control

Use the API to set pressed state imperatively.

<Example id="ToggleProgrammatic">

```tsx
api.setPressed(true)
```

</Example>

### Indicator part

Render an optional element with `getIndicatorProps()` for icons or secondary
visuals. The root remains the interactive `button`.

<Example id="ToggleIndicator">

```tsx
<button {...api.getRootProps()}>
  <span {...api.getIndicatorProps()}>
    <BoldIcon />
  </span>
</button>
```

</Example>
