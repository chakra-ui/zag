A combobox is an input with a popup that lets you select a value from a
collection.

> The value is an item from the list, and the text only searches it. If the
> value is the text itself, like a search box, use
> [Autocomplete](/components/react/autocomplete).

<Resources pkg="@zag-js/combobox" />

<Showcase id="Combobox" />

**Features**

- Single or multiple selection, with removable chips
- Groups, separators, and select-all options
- Creating items from the typed text, synchronously or on a server
- Custom values, disabled items, and links as items
- Works with virtualized lists and async results
- Announces result counts and loading to screen readers

### Filtering items

Filter in `onInputValueChange`. Check `reason`: selecting an item fills the
input with its label, which isn't a query.

Use `createFilter` from `@zag-js/utils/search` to match with the user's locale,
ignoring case and accents. To match text that isn't in the label, like a local
name or a username, test extra keywords too.

<Example id="ComboboxFilter">

```tsx
import { createFilter } from "@zag-js/utils/search"

const { contains } = createFilter({ sensitivity: "base" })

const [query, setQuery] = useState("")

const collection = combobox.collection({
  items: countries.filter((item) =>
    [item.label, ...item.keywords].some((text) => contains(text, query)),
  ),
})

const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  onInputValueChange({ inputValue, reason }) {
    setQuery(reason === "input-change" ? inputValue : "")
  },
})
```

</Example>

`createFilter` also returns `startsWith` and `endsWith`.

### Custom object format

By default, the collection expects items with `label` and `value` properties.
For other shapes, pass these to the collection:

- `itemToString` — the item's label, used for the input and announcements.
- `itemToValue` — the item's unique value, used for `value` and form submission.
- `isItemDisabled` — whether the item is disabled.

<Example id="ComboboxCustomObject">

```tsx
const collection = combobox.collection({
  items: [
    { id: 1, fruit: "Banana", available: true, quantity: 10 },
    { id: 2, fruit: "Apple", available: false, quantity: 5 },
    { id: 3, fruit: "Orange", available: true, quantity: 3 },
    //...
  ],
  itemToString: (item) => item.fruit,
  itemToValue: (item) => String(item.id),
  isItemDisabled: (item) => !item.available || item.quantity === 0,
})
```

</Example>

`value` holds the item values (here, the IDs). Read the full objects from
`api.selectedItems` or `details.items` in `onValueChange`.

### Groups and separators

Pass `groupBy` to the collection and render `collection.group()`. Wrap each
group in `getItemGroupProps` and label it with `getItemGroupLabelProps`, using
the same id. Use `getSeparatorProps` to divide them.

<Example id="ComboboxGroups">

```tsx
const collection = combobox.collection({
  items: cities,
  groupBy: (item) => item.region,
})

<div {...api.getListProps()}>
  {collection.group().map(([region, items], index) => (
    <Fragment key={region}>
      {index > 0 && <hr {...api.getSeparatorProps()} />}
      <div {...api.getItemGroupProps({ id: region })}>
        <div {...api.getItemGroupLabelProps({ htmlFor: region })}>{region}</div>
        {items.map((item) => (
          <div key={item.value} {...api.getItemProps({ item })}>
            {item.label}
          </div>
        ))}
      </div>
    </Fragment>
  ))}
</div>
```

</Example>

Groups with no matching items drop out of `collection.group()` as you filter.

### Empty state

Render `getEmptyProps` inside the content and fill it when there are no items.
Keep the element rendered: it's a live region, so its text is announced. The
content and list also get `data-empty`.

```tsx
<div {...api.getContentProps()}>
  <div {...api.getEmptyProps()}>
    {api.collection.size === 0 && "No countries found"}
  </div>
  <div {...api.getListProps()}>{/* items */}</div>
</div>
```

### Keep the text after choosing

chosen. With `multiple`, users can choose several matches without retyping.

```tsx {4}

  id: useId(),
  collection,

```

> With single selection, the text can differ from the value. When the text is
> the value, use [Autocomplete](/components/react/autocomplete).

### Chips

With `multiple`, show each selected item as a removable chip. Put the chips and
the input inside `getChipGroupProps`.

<Example id="ComboboxChips">

```tsx
<div {...api.getControlProps()}>
  <div {...api.getChipGroupProps()}>
    {api.selectedItems.map((item) => (
      <span key={item.value} {...api.getChipProps({ item })}>
        {item.label}
        <button {...api.getChipDeleteTriggerProps({ item })}>✕</button>
      </span>
    ))}
    <input {...api.getInputProps()} />
  </div>
</div>
```

</Example>

Deleting a chip calls `onValueChange` with `reason: "chip-delete"`. Clicking the
empty space in the chip group focuses the input.

| Key                                | Action                                       |
| ---------------------------------- | -------------------------------------------- |
| `ArrowLeft` at the start of input  | Focuses the last chip                        |
| `Backspace` in an empty input      | Focuses the last chip; press again to delete |
| `ArrowLeft` / `ArrowRight`         | Moves between chips                          |
| `Home` / `End`                     | Focuses the first or last chip               |
| `Backspace` / `Delete` on a chip   | Deletes it and focuses a neighbor            |
| `Escape`, `Enter`, `Space`, typing | Returns to the input                         |
| `ArrowDown` / `ArrowUp` on a chip  | Returns to the input and opens the list      |

For free-form tags that aren't in a list, use the
[tags input](/components/react/tags-input) instead.

### Select all

With `multiple`, render `getSelectAllProps` before the items. It's first in
keyboard order, selects every enabled item in the collection (so only the
matches while filtering), and unselects them once they all are. Use
`getSelectAllState` for its checked or indeterminate state. It renders as an
item with `data-type="select-all"`, so item styles apply.

<Example id="ComboboxSelectAll">

```tsx
const selectAll = api.getSelectAllState()

<div {...api.getListProps()}>
  <div {...api.getSelectAllProps()}>
    {selectAll.indeterminate ? "–" : selectAll.checked ? "✓" : ""}
    {selectAll.checked ? "Unselect all" : "Select all"}
  </div>
  {items.map((item) => (
    <div key={item.value} {...api.getItemProps({ item })}>
      {item.label}
    </div>
  ))}
</div>
```

</Example>

To select everything from outside the list, call `api.selectAll()`. While the
option is highlighted, `highlightedValue` is `combobox.SELECT_ALL_VALUE`.

### Limiting selections

once the limit is reached. Selected items stay enabled so they can be removed.

<Example id="ComboboxMaxSelected">

```tsx
  multiple: true,
  value,
```


</Example>

### Trigger behavior

Use these props to fine-tune when the popup opens:

- `openOnClick` opens it when the input is clicked (default `false`)
- `openOnChange` opens it as the user types (default `true`); pass a function to
  decide per change
- `openOnKeyPress` opens it on `ArrowDown` / `ArrowUp` (default `true`)

<Example id="ComboboxOpenBehavior">

```tsx
const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  openOnClick: true,
  // Wait for two characters before suggesting
  openOnChange: ({ inputValue }) => inputValue.length >= 2,
})
```

</Example>

### Value changes

Use `onValueChange` to listen for selected value changes.

<Example id="ComboboxValueChange">

```tsx {3-6}
const service = useMachine(combobox.machine, {
  onValueChange(details) {
    // details => { value: string[]; items: CollectionItem[]; reason?: ValueChangeReason }
    console.log(details)
  },
})
```

</Example>

`details.reason` says what caused the change.

| Reason          | Meaning                                                      |
| --------------- | ------------------------------------------------------------ |
| `item-select`   | An item was clicked or selected with `Enter`                 |
| `clear-trigger` | The clear trigger was pressed                                |
| `chip-delete`   | A chip was deleted                                           |
| `input-clear`   | The text of a single selection was emptied                   |
| `escape-key`    | `Escape` brought back the value emptying the text cleared    |
| `script`        | Changed programmatically, such as `setValue` or `clearValue` |

With a single selection, emptying the text clears the value, and `Escape` brings
it back while the list is open.

### Form usage

Set `name` and render the hidden input. The form submits each selected item's
value, not its label.

```tsx {3,9}
const service = useMachine(combobox.machine, {
  collection,
  name: "country",
})

return (
  <div {...api.getRootProps()}>
    <input {...api.getInputProps()} />
    <input {...api.getHiddenInputProps()} />
  </div>
)
```

With `multiple`, render one hidden input per value, so the form gets one entry
per item.

```tsx
{
  api.value.map((value) => (
    <input key={value} {...api.getHiddenInputProps({ value })} />
  ))
}
```

If the combobox sits outside the form element, set `form` to the form's id.

```tsx
const service = useMachine(combobox.machine, {
  collection,
  name: "country",
  form: "checkout-form",
})
```

### Creating items

Pass `onCreate` and render `getCreateItemProps` at the end of the list. The
option shows while the input has text that no item is labelled with, and the
arrow keys reach it after the items. It renders as an item with
`data-type="create"`. Add the item to your collection in `onCreate` and return
its value to select it.

<Example id="ComboboxCreate">

```tsx
const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  onCreate({ inputValue }) {
    const item = { label: inputValue, value: inputValue.toLowerCase() }
    setItems((prev) => [...prev, item])
    return item.value
  },
})

const api = combobox.connect(service, normalizeProps)
const create = api.getCreateItemState()

<div {...api.getListProps()}>
  {items.map((item) => (
    <div key={item.value} {...api.getItemProps({ item })}>
      {item.label}
    </div>
  ))}
  <div {...api.getCreateItemProps()}>Create "{create.inputValue}"</div>
</div>
```

</Example>

While the option is highlighted, `highlightedValue` is `combobox.CREATE_VALUE`.

### Creating items on a server

Return a Promise from `onCreate`. While it runs, `getCreateItemState().pending`
is `true` and the option gets `data-loading`. If it rejects, `error` holds the
reason until the text changes.

Closing the list or editing the text aborts `signal`, and the result is ignored.

<Example id="ComboboxCreateAsync">

```tsx
const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  async onCreate({ inputValue, signal }) {
    const item = await createLabel(inputValue, { signal })
    setItems((prev) => [...prev, item])
    return item.value
  },
})

const create = api.getCreateItemState()

<div {...api.getCreateItemProps()}>
  {create.pending
    ? `Creating "${create.inputValue}"…`
    : `Create "${create.inputValue}"`}
  {create.error && <span>{create.error.message}</span>}
</div>
```

</Example>

### Items as links

Render items as `<a>` elements to navigate. Pressing `Enter` on a highlighted
link clicks it. With a client-side router, pass `navigate` to handle it instead.

```tsx
const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  navigate({ href }) {
    router.push(href)
  },
})

{
  items.map((item) => (
    <a key={item.href} href={item.href} {...api.getItemProps({ item })}>
      {item.label}
    </a>
  ))
}
```

### List wrapper

Render the items inside `getListProps()`. The list carries the `listbox` role
and is the scroll container; the content is only a container.

### Input inside the popup

To build a searchable select, open the combobox from a trigger and move the
input into the content:

- Set `popupType` to `"dialog"`, so the content becomes a `dialog`.
- Pass `focusable: true` to `getTriggerProps`, so the trigger stays in the tab
  order and shows the value.

<Example id="ComboboxInputInPopup">

```tsx
const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  popupType: "dialog",
  selectionBehavior: "clear",
})

<div {...api.getControlProps()}>
  <button {...api.getTriggerProps({ focusable: true })}>
    {api.valueAsString || "Select a country"}
  </button>
</div>

<div {...api.getPositionerProps()}>
  <div {...api.getContentProps()}>
    <input {...api.getInputProps()} />
    <div {...api.getListProps()}>
      {collection.items.map((item) => (
        <div key={item.value} {...api.getItemProps({ item })}>
          {item.label}
        </div>
      ))}
    </div>
  </div>
</div>
```

</Example>

### Virtualizing long lists

For thousands of items, render only the visible rows with the
[virtualizer](/utilities/virtualizer). Pass `scrollToIndexFn` so keyboard
navigation scrolls to rows that aren't rendered, and merge the virtualizer's
props with the list and item props.

<Example id="ComboboxVirtualized">

```tsx
const { virtualizer, ref } = useListVirtualizer({
  count: items.length,
  itemSize: 32,
})

const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  scrollToIndexFn(details) {
    virtualizer.scrollToIndex(details.index, {
      align: details.immediate ? "center" : "auto",
    })
  },
})

<div ref={ref} {...mergeProps(virtualizer.getRootProps(), api.getListProps())}>
  <div {...virtualizer.getContentProps()}>
    {virtualizer.getVirtualItems().map((virtualItem) => {
      const item = items[virtualItem.index]
      return (
        <div
          key={item.value}
          {...mergeProps(virtualizer.getItemProps(virtualItem), api.getItemProps({ item }))}
        >
          {item.label}
        </div>
      )
    })}
  </div>
</div>
```

</Example>

`useListVirtualizer` is the hook from the
[virtualizer docs](/utilities/virtualizer). Select-all and create options aren't
virtualized rows; they scroll like any other element.

### Announcements

When the user types, the combobox announces the number of results to screen
readers once the input and results settle ("3 results", "1 result", or "No
results").

When results load asynchronously, pass `loading` while the request is in flight.
The listbox gets `aria-busy="true"`, the loading message is announced instead of
the count, and "No results" is never announced until loading ends.

```tsx
const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  loading: isFetching,
  translations: {
    resultsCount: (count) => `${count} countries found`,
    noResults: "No countries found",
    loading: "Searching countries",
  },
})
```

Other messages you can customize:

- `chipDeleted(label)` — when a chip is deleted
- `creatingItem(inputValue)` — when an async create starts
- `createItemFailed({ inputValue, error })` — when an async create fails
- `highlightedItem({ label, selected })` — when an option is highlighted, on
  Apple platforms

> Set a message to an empty string (or return `""` from a function) to turn that
> announcement off.

## Recipes

### Recent items

Show a short list while the input is empty, and search everything once the user
types. Set `openOnClick` so the recent items appear on focus.

<Example id="ComboboxRecentItems">

```tsx
const [query, setQuery] = useState("")

const collection = combobox.collection({
  items: query
    ? countries.filter((item) => contains(item.label, query))
    : recentCountries,
})

const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  openOnClick: true,
  onInputValueChange({ inputValue, reason }) {
    setQuery(reason === "input-change" ? inputValue : "")
  },
})
```

</Example>

### Command palette

Render an inline combobox inside a dialog to build a command palette. Each item
runs an action instead of holding a value:

- `value: []` keeps nothing selected
- `selectionBehavior: "clear"` empties the input after each command
- `onSelect` looks up the item by `itemValue` and runs it

```tsx
const collection = combobox.collection({
  items: [
    { value: "new-file", label: "New file", run: createFile },
    { value: "settings", label: "Open settings", run: openSettings },
  ],
})

const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  inline: true,
  value: [],
  selectionBehavior: "clear",
  onSelect({ itemValue }) {
    collection.find(itemValue)?.run()
    dialogApi.setOpen(false)
  },
})
```

### Async combobox

Pair the combobox with the [async list](/utilities/async-list) to fetch items as
the user types. The async list aborts stale requests and tracks loading state.

```tsx
import * as asyncList from "@zag-js/async-list"

const listService = useMachine(asyncList.machine, {
  autoReload: true,
  // Keep showing the last results while the next query loads
  keepPreviousItems: true,
  async load({ signal, filter }) {
    const res = await fetch(`/api/people?search=${filter ?? ""}`, { signal })
    const json = await res.json()
    return { items: json.results }
  },
})

const list = asyncList.connect(listService)

const collection = useMemo(
  () => combobox.collection({ items: list.items }),
  [list.items],
)

const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  loading: list.isLoading,
  onInputValueChange({ inputValue, reason }) {
    // Selecting an item fills the input; that shouldn't trigger a search
    if (reason === "item-select") return
    list.setFilter(inputValue)
  },
})
```

Only show the empty message once the search has settled.

```tsx
<div {...api.getEmptyProps()}>
  {list.isEmpty && !list.isLoading && "No results"}
</div>
```

This works with `multiple` too: selected items stay in `api.selectedItems` after
they drop out of the results.

### Loading more results

To paginate, return a `cursor` from `load` and put an
[infinite scroll](/utilities/infinite-scroll) sentinel at the end of the list.
Set `loopFocus: false` so `ArrowDown` on the last item doesn't wrap past the
next page.

```tsx
import * as infiniteScroll from "@zag-js/infinite-scroll"

const scrollService = useMachine(infiniteScroll.machine, {
  id: useId(),
  count: list.items.length,
  hasMore: list.hasMore,
  loading: list.isLoading,
  onLoadMore: () => list.loadMore(),
})

const scroll = infiniteScroll.connect(scrollService, normalizeProps)

const service = useMachine(combobox.machine, {
  id: useId(),
  collection,
  loopFocus: false,
  // Only the first page counts as a search
  loading: list.isLoading && !list.isLoadingMore,
})

<div {...api.getListProps()}>
  {list.items.map((item) => (
    <div key={item.id} {...api.getItemProps({ item })}>
      {item.name}
    </div>
  ))}
  <div {...scroll.getSentinelProps()} />
</div>
```
