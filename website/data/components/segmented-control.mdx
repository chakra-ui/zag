**Features**

- Syncs with `disabled` state of fieldset
- Syncs with form `reset` events
- Can programmatically set segmented control value
- Can programmatically focus segmented control items

## Usage

<CodeSnippet id="segmented-control/usage.mdx" />

### Initial value

Use the `defaultValue` property to set the segmented control's initial value.

<Example id="SegmentedControlDefaultValue">

```tsx {2}
const service = useMachine(radio.machine, {
  defaultValue: "apple",
})
```

</Example>

### Controlled value

Use `value` and `onValueChange` for controlled usage.

<Example id="SegmentedControlControlled">

```tsx
const service = useMachine(radio.machine, {
  value,
  onValueChange(details) {
    setValue(details.value)
  },
})
```

</Example>

### Programmatic value

Use the connected API when you need imperative updates.

<Example id="SegmentedControlProgrammatic">

```tsx
api.setValue("orange")
api.clearValue()
```

</Example>

### Programmatic focus

Use `api.focus()` to move focus to the selected item (or first enabled item).

<Example id="SegmentedControlFocus">

```tsx
api.focus()
```

</Example>

### Value changes

When the segmented control value changes, the `onValueChange` callback is
invoked.

<Example id="SegmentedControlValueChange">

```tsx {2-7}
const service = useMachine(radio.machine, {
  onValueChange(details) {
    // details => { value: string | null }
    console.log("segmented control value is:", details.value)
  },
})
```

</Example>

### Form usage

To use segmented control in forms, set `name` and render
`api.getItemHiddenInputProps({ value })` for each item.

<Example>

```tsx {2}
const service = useMachine(radio.machine, {
  name: "fruits",
})
```

</Example>

### Vertical orientation

Set `orientation` when you need a vertical layout.

<Example id="SegmentedControlVertical">

```tsx
const service = useMachine(radio.machine, {
  orientation: "vertical",
})
```

</Example>

## Styling

### Indicator

Animate the indicator with a CSS transition. It gets `data-instant` when it
should snap instead (first render or resize), and the items get
`data-indicator-pending` until it's measured.

```css
[data-radio-group-indicator] {
  width: var(--width);
  height: var(--height);
  transition:
    left 0.2s,
    width 0.2s;
}

[data-radio-group-indicator][data-instant] {
  transition: none;
}

/* Server render or hidden container: style the checked item instead */
[data-radio-group-item][data-state="checked"][data-indicator-pending] {
  background: white;
}
```
