## Usage

Import the rating package:

```tsx
import * as rating from "@zag-js/rating-group"
```

The rating package exports two key functions:

- `machine` - State machine logic.
- `connect` - Maps machine state to JSX props and event handlers.

Then use the framework integration helpers:

<CodeSnippet id="rating-group/usage.mdx" />

### Initial value

Use the `defaultValue` property to set the rating's initial value.

<Example id="RatingInitialValue">

```tsx {2}
const service = useMachine(rating.machine, {
  defaultValue: 2.5,
})
```

</Example>

### Controlled value

Use `value` and `onValueChange` to control the rating externally.

<Example id="RatingControlled">

```tsx
const service = useMachine(rating.machine, {
  value,
  onValueChange(details) {
    setValue(details.value)
  },
})
```

</Example>

### Programmatic value

Use `api.setValue` or `api.clearValue` when you need imperative control.

<Example id="RatingSetValue">

```tsx
api.setValue(4)
api.clearValue()
```

</Example>

### Allowing half items

Enable `allowHalf` when your UX needs fractional ratings.

<Example id="RatingHalf">

```tsx
const service = useMachine(rating.machine, {
  allowHalf: true,
})
```

</Example>

### Value changes

When the rating value changes, the `onValueChange` callback is invoked.

<Example id="RatingValueChange">

```tsx {2-7}
const service = useMachine(rating.machine, {
  onValueChange({ value }) {
    console.log("rating value is:", value)
    // 1 | 2.5 | 4
  },
})
```

</Example>

### Hover changes

Use `onHoverChange` to react to hover previews before selection.

<Example id="RatingHoverChange">

```tsx
const service = useMachine(rating.machine, {
  onHoverChange(details) {
    console.log("hovered rating:", details.hoveredValue)
  },
})
```

</Example>

### Value text

Use `translations.ratingValueText` to customize how each rating item is
announced.

<Example>

```tsx
const service = useMachine(rating.machine, {
  translations: {
    ratingValueText: (index) => `${index} out of 5`,
  },
})
```

</Example>

### Form usage

To use rating in forms, set `name` and render `api.getHiddenInputProps()`.

<Example>

```tsx {2}
const service = useMachine(rating.machine, {
  name: "rating",
})
```

</Example>

## Styling guide

Each part includes a component-scoped data attribute you can target in CSS.

### Disabled state

When the rating is disabled, the `data-disabled` attribute is added to the item,
control and label parts.

```css
[data-rating-group-item][data-disabled] {
  /* styles for item disabled state */
}

[data-rating-group-label][data-disabled] {
  /* styles for label disabled state */
}

[data-rating-group-control][data-disabled] {
  /* styles for control disabled state */
}
```

### Checked state

When the rating is checked, the `data-checked` attribute is added to the item
part.

```css
[data-rating-group-item][data-checked] {
  /* styles for rating checked state */
}
```

### Read-only state

When the rating is readonly, the `data-readonly` attribute is added to the item
part.

```css
[data-rating-group-item][data-readonly] {
  /* styles for rating readonly state */
}
```

### Highlighted

When an item is highlighted, the `data-highlighted` attribute is added to the
item part.

```css
[data-rating-group-item][data-highlighted] {
  /* styles for highlighted item */
}
```

### Half rating

When an item is half, the `data-half` attribute is added to the item part.

```css
[data-rating-group-item][data-half] {
  /* styles for half item */
}
```
