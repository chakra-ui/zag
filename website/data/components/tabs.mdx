<Resources pkg="@zag-js/tabs" />

<Showcase id="Tabs" />

**Features**

- Supports mouse, touch, and keyboard interactions on tabs
- Supports LTR and RTL keyboard navigation
- Follows the tabs ARIA pattern, semantically linking tabs and their associated
  tab panels
- Focus management for tab panels without any focusable children

## Usage

<CodeSnippet id="tabs/usage.mdx" />

### Initial tab

To set the initially selected tab, pass the `defaultValue` property to the
machine's context.

<Example id="TabsInitialValue">

```tsx {2}
const service = useMachine(tabs.machine, {
  defaultValue: "tab-1",
})
```

</Example>

Subsequently, you can use the `api.setValue` function to programmatically set
the selected tab.

```tsx
api.setValue("tab-2")
```

To clear selection (when `deselectable` is enabled), use:

```tsx
api.clearValue()
```

### Orientation

The default orientation of the tabs is horizontal. To change the orientation,
set the `orientation` property in the machine's context to `"vertical"`.

<Example id="TabsVertical">

```tsx {2}
const service = useMachine(tabs.machine, {
  orientation: "vertical",
})
```

</Example>

### Disabled tab

To disable a tab, set the `disabled` property in the `getTriggerProps` to
`true`.

When a Tab is `disabled`, it is skipped during keyboard navigation and it is not
clickable.

<Example id="TabsDisabled">

```tsx
//...
<button {...api.getTriggerProps({ disabled: true })}></button>
//...
```

</Example>

### Events

- `onValueChange` — Callback invoked when the selected tab changes.
- `onFocusChange` — Callback invoked when the focused tab changes.

<Example id="TabsEvents">

```tsx {2-7}
const service = useMachine(tabs.machine, {
  onFocusChange(details) {
    // details => { focusedValue: string | null }
    console.log("focused tab:", details.focusedValue)
  },
  onValueChange(details) {
    // details => { value: string | null }
    console.log("selected tab:", details.value)
  },
})
```

</Example>

### Deselection

Set `deselectable` to allow clicking the active tab to clear the current value.

<Example id="TabsDeselectable">

```tsx
const service = useMachine(tabs.machine, {
  deselectable: true,
})
```

</Example>

### Link tabs

Use `navigate` when your tab triggers are rendered as links.

<Example>

```tsx
const service = useMachine(tabs.machine, {
  navigate(details) {
    // details => { value: string, node: HTMLAnchorElement, href: string }
    router.push(details.href)
  },
})
```

</Example>

### Manual activation

By default, a tab is selected when it receives focus from either keyboard or
pointer interaction. This is called "automatic tab activation".

The other approach is "manual tab activation" which means the tab is selected
with the Enter key or by clicking on the tab.

<Example id="TabsManual">

```tsx {2}
const service = useMachine(tabs.machine, {
  activationMode: "manual",
})
```

</Example>

### Loop navigation

Set `loopFocus` to control whether arrow-key navigation wraps at the ends.

<Example id="TabsNoLoop">

```tsx
const service = useMachine(tabs.machine, {
  loopFocus: false,
})
```

</Example>

### RTL support

The tabs machine provides support right to left writing directions. In this
mode, the layout and keyboard interaction is flipped.

To enable RTL support, set the `dir` property in the machine's context to `rtl`.

<Example id="TabsRtl">

```tsx {2}
const service = useMachine(tabs.machine, {
  dir: "rtl",
})
```

</Example>

### Programmatic control

Use the connected API for imperative navigation and focus.

<Example id="TabsProgrammatic">

```tsx
api.setValue("tab-2")
api.selectNext()
api.selectPrevious()
api.focus()
```

</Example>

## Styling

### Tab indicator

Animate the indicator with a CSS transition. It gets `data-instant` when it
should snap instead (first render, resize, `dir` or `orientation` change), and
the triggers get `data-indicator-pending` until it's measured.

```css
[data-tabs-indicator] {
  width: var(--width);
  height: var(--height);
  transition:
    left 0.2s,
    width 0.2s;
}

[data-tabs-indicator][data-instant] {
  transition: none;
}

/* Server render or hidden container: style the selected trigger instead */
[data-tabs-trigger][data-selected][data-indicator-pending] {
  background: white;
}
```

### Animated panels

Every part gets `data-activation-direction`: where the selected tab sits
relative to the previous one (`left`, `right`, `up`, `down` or `none`). It's
also available as `api.activationDirection`, in `onValueChange`, and in
`api.getContentState()` and `api.getIndicatorState()`.

To animate panels in and out, keep the previous panel mounted while it exits
(for example with [Presence](/components/presence)) and slide panels based on
the direction.

```css
[data-tabs-content] {
  --slide: 50%;
  grid-area: 1 / 1;
}

[data-tabs-content][data-activation-direction="left"] {
  --slide: -50%;
}

[data-tabs-content][data-state="open"] {
  animation: slide-in 300ms ease-out;
}

[data-tabs-content][data-state="closed"] {
  animation: slide-out 300ms ease-out forwards;
}

@keyframes slide-in {
  from {
    opacity: 0;
    transform: translateX(var(--slide));
  }
}

@keyframes slide-out {
  to {
    opacity: 0;
    transform: translateX(calc(var(--slide) * -1));
  }
}
```
