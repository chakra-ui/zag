Progress shows how far along a task is, such as downloading a file or uploading
an image. The same machine renders a linear bar or a circle.

**Features**

- Linear and circular shapes from one machine
- Supports minimum and maximum values
- Supports indeterminate progress

## Usage

Import the progress package:

```tsx
import * as progress from "@zag-js/progress"
```

The progress package exports two key functions:

- `machine` - State machine logic.
- `connect` - Maps machine state to JSX props and event handlers.

> Pass a unique `id` to `useMachine` so generated element ids stay predictable.

Then render the [linear](#linear) or [circular](#circular) parts with the
framework integration helpers.

### Setting the value

Use `defaultValue` for uncontrolled state, or `value` for controlled state.

<Example id="ProgressSetValue">

```tsx {2}
const service = useMachine(progress.machine, {
  defaultValue: 50,
})
```

</Example>

Subsequently, you can use the `api.setValue` method to set the value of the
progress bar.

```tsx
api.setValue(50)
```

### Listening for value changes

Use `onValueChange` to react to progress updates.

<Example id="ProgressValueChange">

```tsx
const service = useMachine(progress.machine, {
  onValueChange(details) {
    // details => { value: number | null }
    console.log(details.value)
  },
})
```

</Example>

### Setting the minimum and maximum values

By default, the progress bar has a minimum value of `0` and a maximum value of
`100`. You can change these values by passing the `min` and `max` options to the
machine.

<Example id="ProgressMinMax">

```tsx {2-3}
const service = useMachine(progress.machine, {
  min: 0,
  max: 1000,
})
```

</Example>

### Using the indeterminate state

The progress component is determinate by default, with the value and max set to
`50` and `100` respectively.

Set `value` to `null` to indicate an indeterminate value for operations whose
progress can't be determined (e.g., attempting to reconnect to a server).

<Example id="ProgressIndeterminate">

```tsx {2}
const service = useMachine(progress.machine, {
  defaultValue: null,
})
```

</Example>

### Customizing value text

Progress bars can only be interpreted by sighted users. To include a text
description to support assistive technologies like screen readers, use the
`valueText` part.

<Example id="ProgressValueText">

```tsx
const service = useMachine(progress.machine, {
  translations: {
    value: ({ value, max }) =>
      value == null ? "Loading..." : `${value} of ${max} items loaded`,
  },
})
```

</Example>

Then you need to render the `valueText` part in your component.

```tsx
<div {...api.getValueTextProps()}>{api.valueAsString}</div>
```

### Localizing percentage formatting

Use `locale` and `formatOptions` to customize number formatting.

<Example id="ProgressLocale">

```tsx
const service = useMachine(progress.machine, {
  locale: "fr-FR",
  formatOptions: { style: "percent", maximumFractionDigits: 1 },
})
```

</Example>

### Setting the size of the circle

Use the `--size` CSS variable to set the size of the circle.

<Example id="ProgressCircleSize">

```css
[data-progress-circle] {
  --size: 400px;
}
```

</Example>

### Setting the thickness of the circle

Use the `--thickness` CSS variable to set the thickness of the ring.

<Example id="ProgressCircleThickness">

```css
[data-progress-circle] {
  --thickness: 4px;
}
```

</Example>

## Styling guide

Each part includes a component-scoped data attribute you can target in CSS.

```css
[data-progress-root] {
  /* Styles for the root part */
}

/* linear */
[data-progress-track] {
  /* Styles for the track part */
}

[data-progress-range] {
  /* Styles for the range part */
}

/* circular */
[data-progress-circle-track] {
  /* Styles for the circle track part */
}

[data-progress-circle-range] {
  /* Styles for the circle range part */
}
```

### Indeterminate state

To style the indeterminate state, you can use the `[data-state=indeterminate]`
selector.

```css
[data-progress-root][data-state="indeterminate"] {
  /* Styles for the root indeterminate state */
}

[data-progress-range][data-state="indeterminate"],
[data-progress-circle-range][data-state="indeterminate"] {
  /* Styles for the range indeterminate state */
}
```
