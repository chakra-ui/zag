A pin input takes a code one character per field and moves focus to the next
field as the user types

<Resources pkg="@zag-js/pin-input" />

<Showcase id="PinInput" />

**Features**

- Automatically focuses the next field on typing and focuses the previous field
  on deletion
- Supports numeric and alphanumeric values
- Supports masking value (for sensitive data)
- Supports copy/paste to autofill all fields
- Supports fast paste SMS-code

## Usage

> You'll need to provide a unique `id` to the `useMachine` hook. This is used to
> ensure every part has a unique identifier.

### Initial value

Set `defaultValue` to define the initial pin value. It must be an array of
strings.

<Example id="PinInputDefaultValue">

```tsx {2}
const service = useMachine(pinInput.machine, {
  defaultValue: ["1", "2", ""],
})
```

</Example>

### Controlled value

Use the `value` and `onValueChange` properties to programmatically control the
value of the pin input.

<Example id="PinInputControlled">

<CodeSnippet id="pin-input/controlled.mdx" />

</Example>

### Input count

Set `count` to define the number of input fields to render.

<Example id="PinInputCount">

```tsx
const service = useMachine(pinInput.machine, {
  count: 6,
})
```

</Example>

### Placeholder

To customize the default pin input placeholder (○) for each input, pass the
`placeholder` prop and set it to your desired value.

<Example id="PinInputPlaceholder">

```tsx {2}
const service = useMachine(pinInput.machine, {
  placeholder: "*",
})
```

</Example>

### Submit on complete

Set `autoSubmit` to automatically submit the owning form when all inputs are
filled.

<Example id="PinInputAutoSubmit">

```tsx {2}
const service = useMachine(pinInput.machine, {
  autoSubmit: true,
})
```

</Example>

### Alphanumeric values

By default, the pin input accepts only number values but you can choose between
`numeric`, `alphanumeric` and `alphabetic` values. To change the input mode,
pass the `type` context property and set its value to `alphanumeric`.

<Example id="PinInputAlphanumeric">

```tsx {2}
const service = useMachine(pinInput.machine, {
  type: "alphanumeric",
})
```

</Example>

### Custom pattern

Use `pattern` to provide a custom regex for validating input values. Each
character entered is checked against this pattern.

<Example id="PinInputPattern">

```tsx {2}
const service = useMachine(pinInput.machine, {
  pattern: "[0-9a-fA-F]", // hex characters only
})
```

</Example>

### OTP mode

Set `otp` to let phones suggest the code from an SMS. The first input gets
`autocomplete="one-time-code"`, and an autofilled or pasted full code fills
every input, whichever one has focus.

<Example>

```tsx {2}
const service = useMachine(pinInput.machine, {
  otp: true,
})
```

</Example>

### Masked input

When collecting private or sensitive information using the pin input, you might
need to mask the value entered, similar to `<input type="password"/>`. Pass the
`mask` context property and set it to `true`.

<Example id="PinInputMask">

```tsx {2}
const service = useMachine(pinInput.machine, {
  mask: true,
})
```

</Example>

### Value changes

The pin input machine invokes several callback functions when the user enters:

- `onValueChange` — Function invoked when the value is changed.
- `onValueComplete` — Function invoked when all fields have been completed (by
  typing or pasting).
- `onValueInvalid` — Function invoked when an invalid value is entered into the
  input. An invalid value is any value that doesn't match the specified "type".

<Example id="PinInputValueChange">

```tsx
const service = useMachine(pinInput.machine, {
  onValueChange(details) {
    // details => { value: string[], valueAsString: string }
    console.log("value changed to:", details.value)
  },
  onValueComplete(details) {
    // details => { value: string[], valueAsString: string }
    console.log("completed value:", details)
  },
  onValueInvalid(details) {
    // details => { index: number, value: string }
    console.log("invalid value:", details)
  },
})
```

</Example>

### Normalizing input

Pasted text drops spaces and any characters that don't match `type` or
`pattern`, so `123 456` and `123-456` both fill as `123456`. Dropped characters
are reported through `onValueInvalid`.

Use `normalizeValue` to transform typed or pasted text before it's checked, for
example to uppercase it.

<Example id="PinInputNormalize">

```tsx
const service = useMachine(pinInput.machine, {
  type: "alphanumeric",
  normalizeValue: (value) => value.toUpperCase(),
})
```

</Example>

### Autofocus

Use `autoFocus` to focus the first input on mount. A focused input always
selects its character, so typing replaces it.

<Example>

```tsx
const service = useMachine(pinInput.machine, {
  autoFocus: true,
})
```

</Example>

### RTL support

The pin input machine supports RTL writing directions. Set `dir` to `rtl`.

When this attribute is set, we attach a `dir` attribute to the root part.

<Example id="PinInputRtl">

```tsx {2}
const service = useMachine(pinInput.machine, {
  dir: "rtl",
})
```

</Example>

### External form

Set `form` if the hidden input should submit with a form outside the current DOM
subtree. Use `required` to mark the input as required for form validation.

<Example>

```tsx
const service = useMachine(pinInput.machine, {
  name: "otp",
  form: "checkout-form",
  required: true,
})
```

</Example>

### Accessibility labels

Use `translations.inputLabel` to customize screen-reader labels per input.

<Example>

```tsx
const service = useMachine(pinInput.machine, {
  count: 4,
  translations: {
    inputLabel: (index, length) => `Digit ${index + 1} of ${length}`,
  },
})
```

</Example>
