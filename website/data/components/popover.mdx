A popover is a non-modal panel that floats next to the trigger that opens it,
for contextual content and actions

<Resources pkg="@zag-js/popover" />

<Showcase id="Popover" />

**Features**

- Focus is managed and can be customized
- Supports modal and non-modal modes
- Ensures correct DOM order after tabbing out of the popover
- Supports multiple triggers sharing a single popover instance

## Usage

<CodeSnippet id="popover/usage.mdx" />

The positioner is rendered in a `Portal` (or `Teleport`/`use:portal` depending
on your framework). Zag automatically preserves the correct tab order after the
trigger, even though the content lives elsewhere in the DOM.

### Focus management

When the popover opens, focus moves to the first focusable element. To customize
this, set `initialFocusEl`.

<Example id="PopoverInitialFocus">

<CodeSnippet id="popover/initial-focus.mdx" />

</Example>

To disable automatic focus on open, set `autoFocus` to `false`.

```tsx
const service = useMachine(popover.machine, {
  autoFocus: false,
})
```

### Modality

In some cases, you might want the popover to be **modal**. This means that
it'll:

- trap focus within its content
- block scrolling on the `body`
- disable pointer interactions outside the popover
- hide content behind the popover from screen readers

To make the popover modal, set the `modal: true` property in the machine's
context.

<Example id="PopoverModal">

```tsx {2}
const service = useMachine(popover.machine, {
  modal: true,
})
```

</Example>

### Close behavior

The popover is designed to close on blur and when the `esc` key is pressed.

To prevent it from closing on blur (clicking or focusing outside), pass the
`closeOnInteractOutside` property and set it to `false`.

<Example id="PopoverCloseBehavior">

```tsx {2}
const service = useMachine(popover.machine, {
  closeOnInteractOutside: false,
})
```

</Example>

To prevent it from closing when the `esc` key is pressed, pass the
`closeOnEscape` property and set it to `false`.

```tsx {2}
const service = useMachine(popover.machine, {
  closeOnEscape: false,
})
```

### Controlled open

Use `open` and `onOpenChange` to control visibility externally.

<Example id="PopoverControlled">

```tsx
const service = useMachine(popover.machine, {
  open,
  onOpenChange(details) {
    setOpen(details.open)
  },
})
```

</Example>

### Adding an arrow

To render an arrow within the popover, use the `api.getArrowProps()` and
`api.getArrowTipProps()`.

<Example id="PopoverArrow">

```tsx {6-8}
//...
const api = popover.connect(service, normalizeProps)
//...
return (
  <div {...api.getPositionerProps()}>
    <div {...api.getContentProps()}>
      <div {...api.getArrowProps()}>
        <div {...api.getArrowTipProps()} />
      </div>
      //...
    </div>
  </div>
)
//...
```

</Example>

### Placement

To change the placement of the popover, set the `positioning.placement` property
in the machine's context.

<Example id="PopoverPlacement">

```tsx {2-4}
const service = useMachine(popover.machine, {
  positioning: {
    placement: "top-start",
  },
})
```

</Example>

### Open state changes

When the popover is opened or closed, the `onOpenChange` callback is invoked.

<Example id="PopoverOpenChange">

```tsx {2-7}
const service = useMachine(popover.machine, {
  onOpenChange(details) {
    // details => { open: boolean }
    console.log("Popover", details.open)
  },
})
```

</Example>

### Multiple triggers

A single popover instance can be shared across multiple trigger elements. Pass a
`value` to `getTriggerProps` to identify each trigger.

<Example id="PopoverMultipleTriggers">

```tsx
const service = useMachine(popover.machine, {
  onTriggerValueChange({ value }) {
    console.log("active trigger:", value)
  },
})

const api = popover.connect(service, normalizeProps)

return (
  <>
    <button {...api.getTriggerProps({ value: "info" })}>Info</button>
    <button {...api.getTriggerProps({ value: "help" })}>Help</button>
    <div {...api.getPositionerProps()}>
      <div {...api.getContentProps()}>
        {api.triggerValue === "info" ? "Info content" : "Help content"}
      </div>
    </div>
  </>
)
```

</Example>

When the popover is open and a different trigger is clicked, it repositions
without closing. Focus returns to the correct trigger on close.

### Inside a dialog

When using the popover within a dialog, avoid rendering the popover in a
`Portal` or `Teleport`. This is because the dialog will trap focus within it,
and the popover will be rendered outside the dialog.

## Styling

### Scrollbar width

When `modal` is `true`, Zag applies `--scrollbar-width` on the root element. Use
this CSS variable to keep fixed or sticky elements aligned when the popover
opens and body scrolling is locked.

```css
.app-header {
  position: fixed;
  inset-inline-end: calc(1rem + var(--scrollbar-width, 0px));
}
```

### Arrow

The arrow element requires specific css variables to be set for it to show
correctly.

```css
[data-popover-arrow] {
  --arrow-background: white;
  --arrow-size: 16px;
}
```

A common technique for adding a shadow to the arrow is to use
`filter: drop-shadow(...)` on the content element. Alternatively, you can use
the `--arrow-shadow-color` variable.

```css
[data-popover-arrow] {
  --arrow-shadow-color: gray;
}
```
