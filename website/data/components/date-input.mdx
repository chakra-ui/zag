A date input lets you enter a date by typing into segmented input fields (month,
day, year, etc.) with validation and keyboard navigation.

> **Good to know**: The date input is built on top of the
> [`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/CalendarDate.html)
> library.

<Resources pkg="@zag-js/date-input" />

<Showcase id="DateInput" />

**Features**

- Segmented input fields for each date part (month, day, year, hour, minute,
  second)
- Supports `single` and `range` selection modes
- Keyboard navigation and auto-advance between segments
- Placeholder management with visual distinction
- Customizable granularity (day, hour, minute, second)
- Optional leading zeros in numeric fields
- Works with localization and timezone
- Full accessibility with keyboard and screen reader support
- Form integration with hidden input element

## Usage

Import the package:

```tsx
import * as dateInput from "@zag-js/date-input"
```

These are the key exports:

- `machine` - State machine logic.
- `connect` - Maps machine state to JSX props and event handlers.
- `parse` - Parses an ISO 8601 date string.

> You'll also need to provide a unique `id` to the `useMachine` hook. This is
> used to ensure that every part has a unique identifier.

Then use the framework integration helpers:

<CodeSnippet id="date-input/usage.mdx" />

### Rendering segments

Use `api.getSegments()` to get the list of date segments. Each segment has a
`type` (e.g., `"month"`, `"day"`, `"year"`, `"literal"`) and a `text` property
for display.

<Example id="DateInputSegments">

```tsx
<div {...api.getControlProps()}>
  <div {...api.getSegmentGroupProps()}>
    {api.getSegments().map((segment, i) => (
      <span key={i} {...api.getSegmentProps({ segment })}>
        {segment.text}
      </span>
    ))}
  </div>
</div>
```

</Example>

For range mode, pass the `index` to distinguish start and end date segments:

```tsx
<div {...api.getControlProps()}>
  <div {...api.getSegmentGroupProps({ index: 0 })}>
    {api.getSegments({ index: 0 }).map((segment, i) => (
      <span key={i} {...api.getSegmentProps({ segment, index: 0 })}>
        {segment.text}
      </span>
    ))}
  </div>

  <span> – </span>

  <div {...api.getSegmentGroupProps({ index: 1 })}>
    {api.getSegments({ index: 1 }).map((segment, i) => (
      <span key={i} {...api.getSegmentProps({ segment, index: 1 })}>
        {segment.text}
      </span>
    ))}
  </div>
</div>
```

### Setting the initial date

To set the initial value rendered by the date input, set `defaultValue`.

<Example id="DateInputInitialValue">

```tsx
const service = useMachine(dateInput.machine, {
  defaultValue: [dateInput.parse("2024-01-15")],
})
```

</Example>

### Controlling the selected date

Use `value` and `onValueChange` to programmatically control the selected date.

<Example id="DateInputControlled">

```tsx
const service = useMachine(dateInput.machine, {
  value: [dateInput.parse("2024-01-15")],
  onValueChange(details) {
    // details => { value: DateValue[], valueAsString: string[] }
    console.log("selected date:", details.valueAsString)
  },
})
```

</Example>

You can also set it with `api.setValue`.

```tsx
const nextValue = dateInput.parse("2024-01-15")
api.setValue([nextValue])
```

### Setting the min and max dates

To constrain the dates that can be entered, set the `min` and `max` properties.

<Example id="DateInputMinMax">

```tsx
const service = useMachine(dateInput.machine, {
  min: dateInput.parse("2024-01-01"),
  max: dateInput.parse("2024-12-31"),
})
```

</Example>

When typing values outside the range, invalid segments will be marked as
invalid.

### Disabling the date input

Set `disabled` to `true` to make the input non-interactive.

<Example id="DateInputDisabled">

```tsx
const service = useMachine(dateInput.machine, {
  disabled: true,
})
```

</Example>

### Setting read-only mode

Set `readOnly` to `true` to prevent value changes while allowing focus.

<Example id="DateInputReadOnly">

```tsx
const service = useMachine(dateInput.machine, {
  readOnly: true,
})
```

</Example>

### Required and invalid state

Use `required` and `invalid` for form validation and UI state.

<Example id="DateInputInvalid">

```tsx
const service = useMachine(dateInput.machine, {
  required: true,
  invalid: false,
})
```

</Example>

### Controlling date granularity

Set `granularity` to control the smallest unit displayed in the input.

<Example id="DateInputGranularity">

```tsx
const service = useMachine(dateInput.machine, {
  granularity: "day", // "day" | "hour" | "minute" | "second"
})
```

</Example>

The available granularities are: `"day"`, `"hour"`, `"minute"`, and `"second"`.

### Forcing leading zeros

Set `shouldForceLeadingZeros` to always display leading zeros in numeric fields
(e.g., "01" instead of "1").

<Example id="DateInputLeadingZeros">

```tsx
const service = useMachine(dateInput.machine, {
  shouldForceLeadingZeros: true,
})
```

</Example>

By default, leading zeros follow the locale's conventions.

### Controlling the placeholder date

Use `placeholderValue` to set the initial placeholder date, which is shown in
unfilled segments.

<Example id="DateInputPlaceholder">

```tsx
const service = useMachine(dateInput.machine, {
  placeholderValue: dateInput.parse("2024-01-01"),
  defaultPlaceholderValue: dateInput.parse("2024-01-01"),
})
```

</Example>

Listen for placeholder changes with `onPlaceholderChange`:

```tsx
const service = useMachine(dateInput.machine, {
  onPlaceholderChange(details) {
    // details => { placeholderValue: DateValue, value: DateValue[], valueAsString: string[] }
    console.log("placeholder changed:", details.placeholderValue)
  },
})
```

### Listening to focus changes

Use `onFocusChange` to listen for when the input gains or loses focus.

<Example id="DateInputFocusChange">

```tsx
const service = useMachine(dateInput.machine, {
  onFocusChange(details) {
    // details => { focused: boolean }
    console.log("focused:", details.focused)
  },
})
```

</Example>

### Choosing a selection mode

Use `selectionMode` to allow entering a single date or a date range.

<Example id="DateInputRange">

```tsx
const service = useMachine(dateInput.machine, {
  selectionMode: "range", // "single" | "range"
})
```

</Example>

In range mode, the input will have segments for both start and end dates.

### Working with display values

The `displayValues` property tracks partially entered dates while the user is
typing. This is useful for showing the editing state before a complete date is
entered.

<Example>

```tsx
const displayValues = api.displayValues
// Each incomplete date shows which segments have been filled in
```

</Example>

### Clearing the date

Use `api.clearValue()` to clear the selected date.

<Example id="DateInputClear">

```tsx
api.clearValue()
```

</Example>

### Accessing segments

Use `api.getSegments()` to access the individual date segments.

<Example>

```tsx
const segments = api.getSegments()

segments.forEach((segment) => {
  console.log(segment.type) // "month", "day", "year", etc.
  console.log(segment.text) // displayed text
  console.log(segment.value) // numeric value
  console.log(segment.isEditable) // whether user can edit
})
```

</Example>

Then render each segment:

```tsx
<div {...api.getControlProps()}>
  <div {...api.getSegmentGroupProps()}>
    {api.getSegments().map((segment, i) => (
      <span key={i} {...api.getSegmentProps({ segment })}>
        {segment.text}
      </span>
    ))}
  </div>
</div>
```

### Checking segment editability

Use `api.getSegmentState()` to determine if a segment can be edited.

<Example>

```tsx
const state = api.getSegmentState({ segment })
console.log(state.editable) // true if the segment is editable
```

</Example>

### Using the hidden input for forms

The date input includes a hidden input element for form submission.

<Example>

```tsx
<input {...api.getHiddenInputProps()} />
```

</Example>

Set the `name` attribute to include it in form data:

```tsx
const service = useMachine(dateInput.machine, {
  name: "birthDate",
})
```

Multiple date inputs (range mode) can use a `name` prop on
`getHiddenInputProps`:

```tsx
<input {...api.getHiddenInputProps({ index: 0, name: "startDate" })} />
<input {...api.getHiddenInputProps({ index: 1, name: "endDate" })} />
```

### Labeling the input

Use `getLabelProps()` to properly label the input for accessibility.

<Example>

```tsx
<label {...api.getLabelProps()}>Select a date</label>
<div {...api.getControlProps()}>
  {/* segments */}
</div>
```

</Example>

### Setting locale and timezone

Set `locale` and `timeZone` to control date parsing and formatting.

<Example id="DateInputLocale">

```tsx
const service = useMachine(dateInput.machine, {
  locale: "en-GB",
  timeZone: Intl.DateTimeFormat().resolvedOptions().timeZone,
})
```

</Example>

### Hour cycle (12-hour vs 24-hour time)

Set `hourCycle` to control time format display.

<Example id="DateInputHourCycle">

```tsx
const service = useMachine(dateInput.machine, {
  granularity: "hour",
  hourCycle: 24, // 12 | 24
})
```

</Example>

By default, this is determined by the locale.

### Custom formatter

Provide a `formatter` to customize how dates are parsed and formatted.

<Example id="DateInputFormatter">

```tsx
import { DateFormatter } from "@internationalized/date"

const service = useMachine(dateInput.machine, {
  formatter: new DateFormatter("en-US", {
    dateStyle: "short",
    timeStyle: "short",
  }),
})
```

</Example>

### Form integration

Use the date input within a form with standard HTML form handling:

<Example id="DateInputForm">

```tsx
<form
  onSubmit={(e) => {
    e.preventDefault()
    const formData = new FormData(e.currentTarget)
    const date = formData.get("birthDate")
    console.log("selected date:", date)
  }}
>
  <label {...api.getLabelProps()}>Birth Date</label>
  <div {...api.getControlProps()}>
    <div {...api.getSegmentGroupProps()}>
      {api.getSegments().map((segment, i) => (
        <span key={i} {...api.getSegmentProps({ segment })}>
          {segment.text}
        </span>
      ))}
    </div>
  </div>
  <input {...api.getHiddenInputProps({ name: "birthDate" })} />
  <button type="submit">Submit</button>
</form>
```

</Example>

### Listening to date changes

Use `onValueChange` to listen for date changes.

<Example id="DateInputValueChange">

```tsx
const service = useMachine(dateInput.machine, {
  onValueChange(details) {
    // details => { value: DateValue[], valueAsString: string[] }
```

</Example>

### Localization

Use `translations` to customize accessibility labels and messages.

<Example id="DateInputTranslations">

```tsx
const service = useMachine(dateInput.machine, {
  translations: {
    placeholder: (locale) => ({
      year: "YYYY",
      month: "MM",
      day: "DD",
      hour: "HH",
      minute: "MM",
      second: "SS",
    }),
  },
})
```

</Example>

## Styling guide

Each part includes a component-scoped data attribute you can target in CSS.

```css

  /* styles for the root container */
}

[data-date-input-label] {
  /* styles for the label */
}

[data-date-input-control] {
  /* styles for the control container */
}

[data-date-input-segment-group] {
  /* styles for the segment group */
}

[data-date-input-segment] {
  /* styles for each segment */
}

[data-date-input-hidden-input] {
  /* styles for the hidden input */
}
```

### State attributes

```css
[data-date-input-root] {
  &[data-disabled] {
    /* styles for disabled state */
  }

    /* styles for read-only state */

    /* styles for invalid state */
```
