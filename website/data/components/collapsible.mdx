### Initial state

Set `defaultOpen` to control the initial open state.

<Example id="CollapsibleInitialOpen">

```tsx
const service = useMachine(collapsible.machine, {
  defaultOpen: true,
})
```

</Example>

### Controlled open

Use `open` and `onOpenChange` to control the open state externally.

<Example id="CollapsibleControlled">

<CodeSnippet id="collapsible/controlled.mdx" />

</Example>

### Value changes

When the collapsible state changes, the `onOpenChange` callback is invoked.

<Example id="CollapsibleOpenChange">

```tsx {2-5}
const service = useMachine(collapsible.machine, {
  onOpenChange(details) {
    // details => { open: boolean, reason?: OpenChangeReason }
    console.log("collapsible open:", details.open)
  },
})
```

</Example>

`details.reason` says what caused the change.

| Reason          | Meaning                                                    |
| --------------- | ---------------------------------------------------------- |
| `trigger-click` | The trigger was pressed                                    |
| `find-in-page`  | The browser's find-in-page revealed a match in the content |
| `script`        | Changed programmatically, such as `setOpen`                |

### Disabled state

Set `disabled` to `true` to disable interaction.

<Example id="CollapsibleDisabled">

```tsx {2}
const service = useMachine(collapsible.machine, {
  disabled: true,
})
```

</Example>

### Find-in-page

Set `hiddenUntilFound` to keep the closed content searchable with the browser's
find-in-page. When a match is found inside it, the collapsible opens and the
match shows without the open animation.

<Example id="CollapsibleHiddenUntilFound">

```tsx {2}
const service = useMachine(collapsible.machine, {
  hiddenUntilFound: true,
})
```

</Example>

In controlled mode, the open goes through `onOpenChange`. If `open` isn't
updated, the content is hidden again.

> With server-side rendering, frameworks like React render `hidden` as a
> boolean, so closed content ships as `hidden=""` and only becomes searchable
> after hydration.

### Partial collapse

Use `collapsedHeight` or `collapsedWidth` to create a "partially collapsed"
state. When collapsed, the content keeps the specified minimum size instead of
collapsing to `0px`.

<Example id="CollapsiblePartial">

```tsx {3}
const service = useMachine(collapsible.machine, {
  // Content shows 100px height when collapsed
  collapsedHeight: "100px",
})
```

</Example>

This is useful for creating "show more/less" content sections or preview states
where a portion of the content shows even when collapsed.

### After close animation

Use `onExitComplete` to run code when the close animation finishes.

<Example id="CollapsibleExitComplete">

```tsx
const service = useMachine(collapsible.machine, {
  onExitComplete() {
    console.log("Collapsible is fully closed")
  },
})
```

</Example>

### Animation

Use CSS animations to animate the collapsible when it expands and collapses. The
`--height` and `--width` custom properties are attached to the content part.

<Example id="CollapsibleAnimation">

```css
@keyframes expand {
  from {
    height: var(--collapsed-height, 0);
  }
  to {
    height: var(--height);
  }
}

@keyframes collapse {
  from {
    height: var(--height);
  }
  to {
    height: var(--collapsed-height, 0);
  }
}

[data-collapsible-content] {
  overflow: hidden;
  max-width: 400px;
}

[data-collapsible-content][data-state="open"] {
  animation: expand 110ms cubic-bezier(0, 0, 0.38, 0.9);
}

[data-collapsible-content][data-state="closed"] {
  animation: collapse 110ms cubic-bezier(0, 0, 0.38, 0.9);
}
```

</Example>

## Styling

### Collapse animation

The collapsible content provides `--width`, `--height`, `--collapsed-width`, and
`--collapsed-height` CSS variables that can be used to create smooth animations.
These variables are automatically calculated and updated based on the content's
dimensions.

```css
[data-collapsible-content][data-state="open"] {
  animation: slideDown 200ms ease;
}

[data-collapsible-content][data-state="closed"] {
  animation: slideUp 200ms ease;
}

@keyframes slideDown {
  from {
    opacity: 0.01;
    height: 0;
  }
  to {
    opacity: 1;
    height: var(--height);
  }
}

@keyframes slideUp {
  from {
    opacity: 1;
    height: var(--height);
  }
  to {
    opacity: 0.01;
    height: 0;
  }
}
```

### Find-in-page and CSS resets

`hiddenUntilFound` renders the closed content with `hidden="until-found"`. A
reset like `[hidden] { display: none }` overrides it and stops find-in-page from
searching the content. Exclude `until-found` from the rule:

```css
[hidden]:not([hidden="until-found"]) {
  display: none;
}
```
