Animates a number by rolling each digit to its new value, like a mechanical
counter. Use it for prices, scores and live metrics.

<Resources pkg="@zag-js/number-flow" />

<Showcase id="NumberFlow" />

**Features**

- Locale-aware formatting through `Intl.NumberFormat`, including currency,
  percent, and non-Latin numeral systems.
- Digits keyed by decimal place, so `999` to `1000` adds one digit instead of
  re-keying the rest mid-roll.
- Each digit takes its own shortest path, or rolls in a direction you force.
- Spins through every intermediate value when you want the count to read as
  motion rather than a jump.
- Driven by CSS transitions, with one shared `requestAnimationFrame` write per
  frame across every instance on the page.
- Snaps straight to the value when the user prefers reduced motion.

## Usage

Unlike most machines in Zag.js, a digit is not one element. You render a strip
of `0-9` cells inside each digit, and the machine translates the strip so the
right cell lands in view.

Rendering takes two collections from the `api`:

- `api.segments` is the formatted value broken into ordered pieces. A segment is
  either a `digit` that rolls, or a `symbol` that does not (group separators,
  currency symbols, signs, decimal points).
- `api.digitCells` is the strip to render inside every digit. It is the same
  array for every digit on the page, and it does not change between renders.

<CodeSnippet id="number-flow/usage.mdx" />

Use `segment.key` as the render key rather than the array index. Keys are
derived from the decimal place, so a digit keeps its identity when the number
grows or shrinks. Keying by index re-creates the DOM on every digit-count change
and drops whatever roll was in flight.

### Initial value

Set `defaultValue` to render a starting value without controlling it.

<Example id="NumberFlowInitialValue">

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  defaultValue: 1234,
})
```

</Example>

### Controlled value

Use `value` and `onValueChange` to drive the number from your own state.

<Example id="NumberFlowControlled">

```tsx {3-7}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  value: price,
  onValueChange(details) {
    // details => { value: number }
    setPrice(details.value)
  },
})
```

</Example>

### Value formatting

Pass `formatOptions` straight through to `Intl.NumberFormat`, and `locale` to
pick the numeral system and separators.

<Example id="NumberFlowFormat">

```tsx {3-4}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  locale: "de-DE",
  formatOptions: { style: "currency", currency: "EUR" },
})
```

</Example>

Non-Latin numeral systems work the same way. The strip renders the locale's own
glyphs, so `ar-EG` rolls through `٠` to `٩`.

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  locale: "ar-EG",
})
```

### Prefix and suffix

Use `prefix` and `suffix` for text that sits outside the formatted number and
never rolls.

<Example id="NumberFlowAffix">

```tsx {3-4}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  prefix: "~",
  suffix: " req/s",
})
```

</Example>

Both are included in `api.valueText`, so screen readers announce them.

### Roll direction

By default each digit takes its own shortest path, so `9` to `0` rolls forward
one step instead of backward nine.

Set `trend` to `true` to make every digit roll in the direction the value moved,
or to `1` or `-1` to force a direction regardless.

<Example id="NumberFlowTrend">

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  trend: true,
})
```

</Example>

> Under sustained input faster than `spinTiming.duration`, a digit will
> occasionally take the short way round instead of the `trend` direction. This
> is deliberate: it guarantees the digit always lands on a rendered cell rather
> than scrolling past the end of its strip and showing nothing.

### Spin through values

Set `continuous` to spin through the intermediate values instead of taking the
nearest path. A change from `0` to `12` rolls the ones digit twelve cells rather
than two.

<Example id="NumberFlowContinuous">

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  continuous: true,
})
```

</Example>

Large jumps are capped at what the strip can show, so the digit spins fewer
times rather than blanking. It always comes to rest on the correct value.

### Tuning the animation

`spinTiming` controls the digit roll. `transformTiming` controls layout changes,
which is what runs when a digit enters or exits.

<Example id="NumberFlowTiming">

```tsx {3-4}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  spinTiming: { duration: "500ms", easing: "ease-out" },
  transformTiming: { duration: "300ms", easing: "ease-out" },
})
```

</Example>

Both take CSS values, not numbers, because the animation runs as a CSS
transition rather than in JavaScript.

### Staggering the digits

Set `stagger` to delay each digit against the one to its left, so the number
settles from most significant to least.

<Example id="NumberFlowStagger">

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  stagger: "25ms",
})
```

</Example>

### Animation events

`onAnimationStart` fires once when a roll begins, and `onAnimationComplete` once
when every digit has settled. A burst of value changes that lands mid-roll
counts as one animation, not one per change.

<Example id="NumberFlowAnimationEvents">

```tsx {3-9}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  onAnimationStart(details) {
    // details => { places: number[] }
    console.log("rolling", details.places)
  },
  onAnimationComplete(details) {
    console.log("settled", details.places)
  },
})
```

</Example>

`places` holds the decimal place of each digit that moved. Place `0` is the ones
column, `-1` the first fraction digit.

### Value announcements

By default the root is exposed as a single image with `aria-label` set to the
formatted value, so assistive technology reads the number rather than the strip
of cells behind it.

Set `live` to announce changes as they happen instead. The value is announced
once the roll settles, so a fast counter does not flood the screen reader with
every intermediate value.

<Example>

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  live: true,
})
```

</Example>

Render `api.announcedValueText` inside `getValueTextProps()`. It holds the
settled value, which is what makes the debounce work.

### Reduced motion

When the user prefers reduced motion, the value snaps into place instead of
rolling. Set `respectMotionPreference` to `false` to roll anyway.

<Example>

```tsx {3}
const service = useMachine(numberFlow.machine, {
  id: useId(),
  respectMotionPreference: false,
})
```

</Example>

## Styling

The machine sets the structural styles inline, so you do not need to write them.
The digit gets `overflow: hidden` and a fixed `1lh` height, the track is a flex
column, and each cell is `1lh` tall. That is what clips the strip to one line
and keeps the roll aligned to the text baseline. Digits and symbols are also
single-column grids, which is how their width animates when they enter or exit.

What is left to you is typography and color:

```css
[data-number-flow-root] {
  font-variant-numeric: tabular-nums;
}

[data-number-flow-digit] {
  vertical-align: top;
}

[data-number-flow-digit-cell] {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

> Use a font with tabular figures. Proportional digits change width as they
> roll, which makes the number jitter.

### Edge fade

By default a rolling digit is cut off sharply at the top and bottom of its line.
Add a mask to fade it out instead:

```css
[data-number-flow-digit] {
  --mask-height: 0.15em;
  mask-image: linear-gradient(
    to bottom,
    transparent,
    #000 var(--mask-height),
    #000 calc(100% - var(--mask-height)),
    transparent
  );
}
```

### Trend state

Use the `[data-trend]` attribute to style by the direction of the last change.
It holds `up`, `down`, or `none`, and stays set for the whole roll.

```css
[data-number-flow-root][data-trend="up"] {
  color: green;
}

[data-number-flow-root][data-trend="down"] {
  color: red;
}
```

### Data attributes

Each part has a `data-number-flow-<part>` attribute. Combine it with the state
attributes below to style each state.

`data-entering` and `data-exiting` mark a digit or symbol that is being added or
removed. Each digit has `data-place`, its decimal place counted from the decimal
point. Symbols have `data-type`, their `Intl` part type such as `currency`.
`data-reduced-motion` is present when animations are suppressed.
