Add `@zag-js/wheel-picker`, an iOS-style single-column picker with drag inertia, mouse-wheel scrolling and snapping to
the nearest option.

- Controlled and uncontrolled values, finite and infinite collections, and disabled options.
- Arrow keys, Home/End and typeahead, with spinbutton semantics.
- A hidden select keeps the value in native forms.
- Multi-column pickers, like hour, minute and meridiem, compose one machine per column.

`spreadProps` in `@zag-js/vanilla` now skips null nodes.
