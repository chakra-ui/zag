Zag v2 is the first major release since v1. It makes the components you already use more correct, more accessible and
easier to style, and adds 13 new packages for forms, grids, menubars, scheduling and more.

Most of the upgrade is mechanical. Run the codemod first, then work through what it reports:

```sh
npx @zag-js/codemod v2 src
```

It rewrites selectors in CSS, Tailwind classes, templates and tests, renames props and API members, and lists the
changes it can't make for you.

## Highlights

- [One attribute per part](#one-attribute-per-part): `data-scope` and `data-part` become a single `data-{scope}-{part}`
  attribute, so one element can belong to several components.

- [A `list` part for popups](#a-list-part-for-popups): select, combobox and listbox popups can hold search inputs,
  headers and footers next to the list.

- [Filterable menus and selects](#filterable-menus-and-selects): a built-in filter input and empty state for menu and
  select.

- [Change reasons](#change-reasons): `onOpenChange` and `onValueChange` tell you why something changed.

- [Animated trigger switching](#animated-trigger-switching): popover, menu, tooltip and hover card can animate between
  triggers.

- [CSS owns stacking](#css-owns-stacking): Zag no longer sets `z-index` on overlays.

- [Forms](#forms): new field and fieldset components, and form submission that matches native inputs.

- [New packages](#new-packages): field, fieldset, meter, gridlist, menubar, toolbar, infinite scroll, number flow,
  scheduler, drag and drop, virtualizer, fuzzy search and the codemod.

## Requirements

- Preact adapter: Preact 11. The adapter no longer depends on `preact/compat`.

- Solid adapter: Solid 2. Install `solid-js@^2.0.0-rc.19` and `@solidjs/web@^2.0.0-rc.19`.

- Svelte adapter: Svelte `5.29.0` or later.

- Clipboard: the Clipboard API, which needs https or localhost. The `execCommand` fallback is removed.

## One attribute per part

**Breaking:** Replace `data-scope`, `data-part` and `data-ownedby` with a single `data-{scope}-{part}` attribute. An
element can now carry parts from several components, like a button that is both a popover trigger and a tooltip trigger.

```diff
- <button data-scope="dialog" data-part="trigger" data-ownedby="dialog:1">Open</button>
+ <button data-dialog-trigger="dialog:1">Open</button>
```

```diff
- [data-scope="slider"][data-part="thumb"][data-focus] { ... }
+ [data-slider-thumb][data-focus] { ... }
```

The codemod rewrites these selectors. For custom anatomies, `parts.X.attrs` is now a function that takes the id:
`...parts.trigger.attrs(scope.id)`.

## A list part for popups

**Breaking:** In select, combobox and listbox, `role="listbox"` moves from the `content` part to a new `list` part.
`content` becomes a plain wrapper, so the popup can hold a search input, headers or footers. Wrap your items:

```diff
- <ul {...api.getContentProps()}>
-   {items.map((item) => <li {...api.getItemProps({ item })}>...</li>)}
- </ul>
+ <div {...api.getContentProps()}>
+   <ul {...api.getListProps()}>
+     {items.map((item) => <li {...api.getItemProps({ item })}>...</li>)}
+   </ul>
+ </div>
```

- **Breaking:** Replace `composite` with `popupType: "listbox" | "dialog"` in select, combobox and menu.
  `composite: false` becomes `popupType: "dialog"`.

  ```diff
  - select.machine({ composite: false })
  + select.machine({ popupType: "dialog" })
  ```

- **Breaking:** Rename the highlight setter to `setHighlightedValue` in every list component, and pass `null` to clear
  it.

  ```diff
  - api.setHighlightValue("react") // select, combobox, cascade select
  - api.highlightValue("react") // listbox
  + api.setHighlightedValue("react")
  - api.clearHighlightValue()
  + api.setHighlightedValue(null)
  ```

## Filterable menus and selects

- Add a filter input and an empty state to menu and select with `popupType: "dialog"`. You filter the items; the input
  keeps focus while the arrow keys move the highlight.

  ```tsx
  <div {...api.getContentProps()}>
    <input {...api.getInputProps()} />
    <div {...api.getEmptyProps()}>{items.length === 0 && "No results"}</div>
    <div {...api.getListProps()}>{/* items */}</div>
  </div>
  ```

- Add `getEmptyProps()` to combobox and listbox. It's a polite live region, so keep it rendered and toggle its text.

- Add `autoHighlight` to menu, to highlight the first item as the query changes.

## Change reasons

- Add `reason` to `onOpenChange` and `onValueChange`, such as `trigger-click`, `escape-key`, `interact-outside`,
  `keyboard`, `item-select` or `script`. Each component exports `OpenChangeReason` and `ValueChangeReason` types.

- Add an optional reason to `api.setOpen(open, reason)`. It defaults to `script`.

```ts
onOpenChange({ open, reason }) {
  if (!open && reason === "interact-outside") saveDraft()
}
```

## Animated trigger switching

- Add a `viewport` part to popover, menu, tooltip and hover card, so one popup can animate between triggers. Render a
  content per trigger with `getContentProps({ value })` and `getContentValues()`.

- Add `data-activation-direction` and `api.activationDirection` to these, plus navigation menu and tabs, to animate in
  the direction of travel.

- Add `data-instant` when a popup opens or closes without its normal animation, like a focus open or an Escape close, so
  you can skip the transition.

## CSS owns stacking

**Breaking:** Zag no longer sets a `z-index` on any overlay. Set it on the positioner (or the backdrop) in CSS, using
`--layer-index` for the overlay's place in the stack. It stays set while the overlay animates out.

```diff
- [data-popover-content] {
+ [data-popover-positioner] {
-   z-index: 1400;
+   z-index: calc(1400 + var(--layer-index));
  }
```

This covers popover, menu, select, combobox, hover card, tooltip, date picker, color picker, cascade select, dialog,
drawer, floating panel, tour and the toast group. `--z-index` is no longer set anywhere.

## Forms

- **Breaking:** Leave a disabled angle slider or slider out of form submission, and submit the values of a read-only
  file upload or radio group, like native inputs.

  ```diff
    // to keep submitting a value the user can't change, use readOnly
  - slider.machine({ name: "volume", disabled: true })
  + slider.machine({ name: "volume", readOnly: true })
  ```

- **Breaking:** The number input's value is a number, with `null` for an empty field, and it submits the raw number
  through a hidden input. See [Number input](#number-input).

- Add `@zag-js/field` and `@zag-js/fieldset` to label, describe and validate native controls. See
  [New packages](#new-packages).

- Fix a disabled `<fieldset>` not disabling checkbox, switch and tags input.

## Other changes everywhere

- **Breaking:** Spell out "Prev" as "Previous" across the API: the `previousTrigger` part in carousel, date picker,
  pagination and steps, and methods like `scrollPrevious()`, `goToPrevious()`, `goToPreviousPage()`,
  `goToPreviousStep()`, `selectPrevious()` and the tour's `previous()`.

  ```diff
  - <button {...api.getPrevTriggerProps()} />
  + <button {...api.getPreviousTriggerProps()} />
  ```

  The `ids` and `translations` keys, and the tour's `"prev"` action, follow the same rename:

  ```diff
    carousel.machine({
  -   ids: { prevTrigger: "prev" },
  -   translations: { prevTrigger: "Previous slide" },
  +   ids: { previousTrigger: "prev" },
  +   translations: { previousTrigger: "Previous slide" },
    })

  - pagination.machine({ translations: { prevTriggerLabel: "Previous page" } })
  + pagination.machine({ translations: { previousTriggerLabel: "Previous page" } })

  - actions: [{ label: "Prev", action: "prev" }]
  + actions: [{ label: "Previous", action: "previous" }]
  ```

- **Breaking:** Omitting a required prop is now a type error instead of a runtime error.

  ```diff
  - select.machine({ id }) // threw "[zag-js] missing required props" at runtime
  + select.machine({ id, collection }) // now caught by TypeScript
  ```

- **Breaking (Svelte, Vue):** When the same API method is called several times in a row, such as `api.setOpen()`, only
  the last call applies and its change callback fires once, as in React. Read the new state after `tick()` (Svelte) or
  `nextTick()` (Vue).

  ```diff
    api.setOpen(true)
  - console.log(api.open)
  + await tick()
  + console.log(api.open)
  ```

- Add `get<Part>State()` getters, like `getTriggerState()` and `getContentState()`, for every part with derived state.

- Add `hiddenUntilFound` to accordion and collapsible, so closed content is searchable with the browser's find-in-page.
  A match opens it.

- Fix focus, scroll and sync work scheduled for the next frame running after a component unmounts.

- Fix the page freezing when many overlays are open, and closing one overlay also closing unrelated ones opened after
  it.

- Fix the iOS scroll lock resetting the page's scroll position.

## New packages

- **`@zag-js/field`:** Label, describe and validate a native input, textarea or select. Validates with `ValidityState`
  or your own sync or async `validate`, and shows errors on submit, blur or change.

- **`@zag-js/fieldset`:** A native `<fieldset>` with a legend, helper text and error text. Disabling it disables the
  fields inside.

- **`@zag-js/meter`:** A value in a known range, with `low`, `high` and `optimum` regions.

- **`@zag-js/gridlist`:** The WAI-ARIA grid pattern for lists whose items contain buttons or links, with selection,
  typeahead, grouping, virtualization and 2D layouts.

- **`@zag-js/menubar`:** A WAI-ARIA menubar that coordinates standalone `menu` machines.

- **`@zag-js/toolbar`:** A WAI-ARIA toolbar with roving focus across its controls.

- **`@zag-js/infinite-scroll`:** Load paginated content as the user scrolls, at either end, horizontally or in RTL.

- **`@zag-js/number-flow`:** Animate a number change by rolling each digit to its new value.

- **`@zag-js/scheduler`:** A calendar scheduler with day, week, month, year, agenda and timeline views, resources, and
  drag and drop.

- **`@zag-js/dnd`:** Accessible drag and drop for vertical and horizontal lists, with keyboard moves and announcements.

- **`@zag-js/virtualizer`:** A framework-agnostic virtualizer for lists and grids.

- **`@zag-js/fuzzy`:** Match, rank and highlight text, with keywords and multi-word queries.

- **`@zag-js/codemod`:** Upgrade a v1 project with `npx @zag-js/codemod v2 src`.

## Components

### Accordion

- **Breaking:** Remove arrow, `Home` and `End` navigation between triggers, and the `loopFocus` prop, following the
  WAI-ARIA accordion pattern. Triggers are reached with `Tab`.

  ```diff
    accordion.machine({
  -   loopFocus: true,
    })
  ```

- **Breaking:** Default `collapsible` to `true`. Set `collapsible: false` to keep one item open.

  ```diff
  - accordion.machine({})
  + accordion.machine({ collapsible: false })
  ```

### Async list

- **Breaking:** Make filter and sorting state generic, and rename the related props and API.

  | Before                                  | After                                  |
  | --------------------------------------- | -------------------------------------- |
  | `initialFilterText`                     | `initialFilter`                        |
  | `initialSortDescriptor`                 | `initialSorting`                       |
  | `api.setFilterText()` / `api.sort()`    | `api.setFilter()` / `api.setSorting()` |
  | `api.filterText` / `api.sortDescriptor` | `api.filter` / `api.sorting`           |
  | `api.loading` / `api.empty`             | `api.isLoading` / `api.isEmpty`        |

  `load`, `sort` and the machine type take the new names:

  ```diff
  - asyncList.Machine<Item, Cursor>
  + asyncList.Machine<Item, Filter, Sorting, Cursor>

  - async load({ signal, cursor, filterText, sortDescriptor })
  + async load({ signal, cursor, filter, sorting })

  - sort({ items, descriptor, filterText })
  + sort({ items, sorting, filter })
  ```

- Add `keepPreviousItems` to keep items visible while a new filter or sort loads.

### Carousel

- **Breaking:** Rename `slideCount` to `count`, `autoplay` to `autoPlay` and `padding` to `itemSpacing`.

  ```diff
    carousel.machine({
  -   slideCount: 5,
  -   autoplay: true,
  -   padding: "16px",
  +   count: 5,
  +   autoPlay: true,
  +   itemSpacing: "16px",
    })
  ```

- Fix a quick mouse flick snapping back instead of moving to the next page.

### Clipboard

- **Breaking:** Remove the `execCommand` fallback.

- Fix a failed copy showing as copied. `onStatusChange` reports `{ copied: false, error }`.

### Color picker

- Add readable labels and value text to the area and channel sliders, like "Hue" and "210°".

- Fix `PageUp` and `PageDown` resetting a channel slider, vertical sliders running opposite to their gradient, and the
  hue resetting at gray.

### Combobox

- **Breaking:** Replace `disableLayer` with `inline`. An inline combobox is always open and isn't positioned or
  dismissable.

  ```diff
  - combobox.machine({ open: true, disableLayer: true })
  + combobox.machine({ inline: true })
  ```

### Dialog and drawer

- `trapFocus`, `preventScroll` and `modal` now update while the dialog or drawer is open.

- Releasing the focus trap no longer moves focus to the trigger. Focus is restored only on close.

### Floating panel and image cropper

- **Breaking:** Rename resize handle props to `placement`: in floating panel, `axis` and `data-axis` become `placement`
  and `data-placement`, and `resizeTriggerAxes` becomes `resizeTriggerPlacements`. In image cropper, `position` and
  `data-position` become `placement` and `data-placement`, and `handles` becomes `placements`.

  ```diff
  - <div {...api.getResizeTriggerProps({ axis: "se" })} />
  + <div {...api.getResizeTriggerProps({ placement: "se" })} />

  - [data-floating-panel-resize-trigger][data-axis="se"] { ... }
  + [data-floating-panel-resize-trigger][data-placement="se"] { ... }
  ```

### Hover card

- **Breaking:** Report a hover close with the `trigger-hover` reason, like a hover open. Check `!open` to tell them
  apart.

  ```ts
  // before
  onOpenChange({ open, reason }) {
    if (reason === "pointer-leave") {}
  }

  // after
  onOpenChange({ open, reason }) {
    if (!open && reason === "trigger-hover") {}
  }
  ```

### Menu

- Add `collection` and `scrollToIndexFn` for virtualized menus.

- Fix Tab being trapped in an open menu. Tab and Shift+Tab close every open menu and move focus past the trigger.

### Meter and progress

- **Breaking:** Default the value to `min` instead of the midpoint. Pass `defaultValue: 50` to keep the old behavior.

  ```diff
  - progress.machine({ min: 0, max: 100 })
  + progress.machine({ min: 0, max: 100, defaultValue: 50 })
  ```

### Number input

- **Breaking:** The value is a number, with `null` for an empty input. `valueAsNumber` is removed; read the text from
  `formattedValue`.

  ```diff
  - const [value, setValue] = useState("")
  + const [value, setValue] = useState<number | null>(null)

  - api.valueAsNumber
  + api.value
  ```

- **Breaking:** Submit the raw number through a hidden input. Render `getHiddenInputProps()` when you set `name`.

  ```diff
    <input {...api.getInputProps()} />
  + <input {...api.getHiddenInputProps()} />
  ```

- **Breaking:** Remove the default `min` and `max`.

  ```diff
    numberInput.machine({
  +   min: Number.MIN_SAFE_INTEGER,
  +   max: Number.MAX_SAFE_INTEGER,
    })
  ```

- **Breaking:** Render the input as a text field instead of a spinbutton, so VoiceOver on iOS can reach the steppers.
  `translations.valueText` is removed.

  ```diff
    translations: {
  -   valueText: (value) => `${value} units`,
    },
  ```

- **Breaking:** Replace `allowOverflow` and `clampValueOnBlur` with `allowOutOfRange`. An out-of-range value is kept and
  reported as invalid.

  ```diff
  - allowOverflow: true,
  - clampValueOnBlur: false,
  + allowOutOfRange: true,
  ```

- **Breaking:** Rename the `increment-press` and `decrement-press` reasons to `increment-trigger` and
  `decrement-trigger`.

  ```diff
  - if (reason === "increment-press") {}
  + if (reason === "increment-trigger") {}
  ```

- Fix typing with non-Latin digits, negative numbers on iPhone, and the `locale` being ignored without `formatOptions`.

### Pin input

- **Breaking:** Remove `blurOnComplete` (move focus in `onValueComplete`) and `selectOnFocus` (a focused input always
  selects).

  ```diff
    pinInput.machine({
  -   blurOnComplete: true,
  -   selectOnFocus: true,
  +   onValueComplete() {
  +     document.getElementById("verify")?.focus()
  +   },
    })
  ```

- **Breaking:** Rename `sanitizeValue` to `normalizeValue`.

  ```diff
  - sanitizeValue: (value) => value.toUpperCase(),
  + normalizeValue: (value) => value.toUpperCase(),
  ```

- Fill from the first input when a full code is pasted or autofilled into any input.

### Popover

- **Breaking:** Remove `portalled` and `api.portalled`. The popover detects a portalled content and handles tab order
  either way.

  ```diff
  - const Wrapper = api.portalled ? Portal : Fragment
  - <Wrapper>
  + <Portal>
      <div {...api.getPositionerProps()}>...</div>
  - </Wrapper>
  + </Portal>
  ```

### Radio group and tabs

- **Breaking:** Remove the indicator's inline transition and the `--transition-*` variables. Add the transition in CSS,
  and turn it off for `data-instant`.

  ```diff
    [data-tabs-indicator] {
  -   --transition-duration: 0.2s;
  -   --transition-timing-function: ease-in-out;
  +   transition: left 0.2s ease-in-out, width 0.2s ease-in-out;
    }
  +
  + [data-tabs-indicator][data-instant] {
  +   transition: none;
  + }
  ```

- **Breaking:** Replace `data-ssr` with `data-indicator-pending`.

  ```diff
  - [data-tabs-trigger][data-selected][data-ssr] { ... }
  + [data-tabs-trigger][data-selected][data-indicator-pending] { ... }
  ```

### Select

- Add press, drag and release: press the trigger, drag to an item and release to select it.

- Add `initialFocusEl` to move focus into the content on open.

- Fix Tab being trapped in the open list.

### Slider

- **Breaking:** Replace the `aria-label` and `aria-labelledby` arrays with `getAriaLabel` and `getAriaLabelledBy`.

  ```diff
    slider.machine({
  -   "aria-label": ["Minimum price", "Maximum price"],
  +   getAriaLabel: ({ index }) => (index === 0 ? "Minimum price" : "Maximum price"),
    })
  ```

- Accept a number for `origin`, so the track can fill from any value.

### Steps

- **Breaking:** Define steps with an `items` array and address them by string `value` instead of index.

  ```diff
    steps.machine({
  -   count: 3,
  -   defaultStep: 0,
  +   items: [{ value: "shipping" }, { value: "gift", optional: true }, { value: "payment" }],
  +   defaultValue: "shipping",
    })
  ```

  `step` becomes `value`, `onStepChange` becomes `onValueChange`, `setStep(index)` becomes `setValue(value)`, and the
  completed screen is `steps.COMPLETE`. See the steps docs for the full mapping.

  The progress CSS variable is renamed:

  ```diff
  - width: var(--percent);
  + width: var(--steps-percent);
  ```

- Add `optional`, `disabled` and `editable` items, a `skipTrigger` part and keyboard navigation in the step list.

### Tabs

- **Breaking:** Replace `composite` with `virtualFocus`. The boolean is inverted: `composite: false` becomes
  `virtualFocus: true`.

  ```diff
  - tabs.machine({ composite: false })
  + tabs.machine({ virtualFocus: true })
  ```

- **Breaking:** Type `value` in `onValueChange` and `focusedValue` in `onFocusChange` as `string | null`. They're `null`
  after deselecting, and when focus leaves the list.

  ```diff
    onValueChange({ value }) {
  -   setTab(value)
  +   if (value != null) setTab(value)
    }
  ```

- Fix the indicator not following the selected tab when tabs are reordered, added or removed.

### Tags input

- **Breaking:** Default `editable` to `false`. Set `editable: true` to keep inline editing.

  ```diff
    tagsInput.machine({
  +   editable: true,
    })
  ```

### Toast

- **Breaking:** Add the `content` part. Wrap the title and description in `getContentProps()` so the toast's height
  keeps updating.

  ```diff
    <div {...api.getRootProps()}>
  -   <h3 {...api.getTitleProps()}>{api.title}</h3>
  -   <p {...api.getDescriptionProps()}>{api.description}</p>
  +   <div {...api.getContentProps()}>
  +     <h3 {...api.getTitleProps()}>{api.title}</h3>
  +     <p {...api.getDescriptionProps()}>{api.description}</p>
  +   </div>
    </div>
  ```

- **Breaking:** `--duration` is now the toast's total duration, not the time remaining, so a progress bar no longer
  jumps after a pause. Drive the bar's animation from it and pause it with `data-paused`.

  ```css
  .toast-progressbar {
    animation: shrink var(--duration) linear forwards;
  }

  [data-toast-root][data-paused] .toast-progressbar {
    animation-play-state: paused;
  }
  ```

- Add swipe to dismiss, with `swipeDirections`.

### Toggle and toggle group

- **Breaking:** Use toggle button semantics in toggle group: items use `aria-pressed` instead of radio roles.

  ```diff
  - [data-toggle-group-item][aria-checked="true"] { ... }
  + [data-toggle-group-item][aria-pressed="true"] { ... }
  ```

- **Breaking:** Remove `data-focus` (use `:focus-visible`) and `data-state="on|off"` (use `data-pressed`).

  ```diff
  - [data-toggle-group-item][data-focus] { ... }
  + [data-toggle-group-item]:focus-visible { ... }

  - [data-toggle-root][data-state="on"] { ... }
  + [data-toggle-root][data-pressed] { ... }
  ```

### Table of contents

- **Breaking:** Default `multiple` to `false`, so only the topmost visible heading is active.

  ```diff
  - toc.machine({})
  + toc.machine({ multiple: true })
  ```
